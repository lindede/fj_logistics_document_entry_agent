# 中国航运单 / 托运单样张

目录：`data/samples/cn_shipping_orders/`

## 说明

公开渠道很少能拿到可再分发的中国出口**实单**扫描件。本目录以中文落货纸版式为主，并填入教学用虚构字段，供 `html` / `html_mix` 等模式试抽。

版式与现有 `BKG.pdf` 不完全相同；`html_struct` 规则抽取对这些样张**不适用或效果差**，属预期。

## 文件

| 文件 | 说明 |
|------|------|
| `cosco_taiwan_shipping_order.pdf` | 中远海运（台湾）公开空白落货纸原件 |
| `cosco_taiwan_shipping_order_filled.pdf` | 在空白落货纸上叠印教学填写内容 |
| `cn_shipping_order_blank_template.pdf` | 中文落货纸栏目示意（已填样例） |
| `cn_export_shipping_order_filled.pdf` | 出口货物托运单（填好） |
| `cn_container_dock_receipt_filled.pdf` | 集装箱货物托运单/场站收据风格（填好） |

业务金标准实样仍用：`../BKG.pdf`。
